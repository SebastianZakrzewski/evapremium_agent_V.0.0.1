## Router

`model: "provider/model-id"` — Mastra czyta env providera. Nie importuj SDK OpenAI.

DeepSeek:

- Env: `DEEPSEEK_API_KEY`
- Prefix: `deepseek/*`
- Agent MVP: `model: "deepseek/deepseek-flash"` (V4.1-Flash)

Klucz tylko na serwerze (Hetzner). Nigdy w widgecie.

Opcjonalnie obiekt z `url: "https://api.deepseek.com"` jeśli trzeba nadpisać host.

W **Mastra** string routera = `deepseek/` + id API DeepSeek (`deepseek-flash` = V4.1-Flash).

Inne prefiksy (nie używać na MVP): cała lista na stronie env — nie kopiować tutaj.
